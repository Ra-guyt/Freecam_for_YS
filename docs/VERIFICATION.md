# Verification

対象はFreecam for YS `1.0.3+mc26.2`、Minecraft 26.2 / Fabric / Java 25です。

## 自動テスト

```powershell
.\gradlew.bat clean test build --console=plain
.\gradlew.bat runClientGameTest --console=plain
```

Linuxでは`./gradlew`を使います。クライアントテストには描画可能な環境が必要です。
テスト用ソースは配布JARへ入りません。

- `CameraSafetyPolicyTest`で50ブロック境界、3次元距離、非有限値の拒否を検査
- クライアント統合テストでワールドへ接続し、Freecamの開始・再開・終了を検査
- 読込済みの空中への移動を許可し、範囲外・ブロック内部への移動と範囲外の公開移動APIを拒否
- 使用中のブロック破壊・アイテム使用を拒否
- F1相当のHUD非表示中にウォーターマーク付きスクリーンショットを取得
- Full Brightnessを有効にした描画と、被ダメージ時の自動終了を検査

## 配布物確認

成果物は`build/libs/freecam_for_ys-fabric-1.0.3+mc26.2.jar`です。

- 別のクリーンなチェックアウトからビルドし、JARをバイト単位で比較
- ソース、到達可能なGit履歴、JARと同梱依存JARを対象に、個人情報・ローカル絶対パス・認証情報・秘密鍵を検査
- PNGの不要なメタデータ、予期しない実行形式やスクリプト、MODメタデータを検査
- LICENSE、NOTICE.md、上流と依存ライブラリの帰属を維持
- 公開済みのJARは差し替えず、内容変更時は新しいバージョンで公開

26.2への移植ではAPIが変わるため、以前の版とクラスファイルは一致しません。
50ブロック制限、衝突、操作遮断、終了条件、ウォーターマークの設計は維持しています。

## 確認範囲

ローカルのクライアント統合テストはシングルプレイで実施します。
実サーバー、Irisなどの追加MOD、Vulkanを含むすべての描画環境の動作保証ではありません。
利用目的や録画後の切り抜きまでクライアントMODで制限することはできません。
