# Verification

## 対象

Freecam for YS `1.0.2+mc1.21.10`の公開候補と、そこからJava 21で作成するFabric JARを確認します。

## ローカル確認結果

- 独立した2つのクリーンなWindowsチェックアウトでビルドとテストが成功
- 2つのチェックアウトから作成したJARがバイト単位で一致
- `CameraSafetyPolicyTest`の境界テスト4件がすべて成功
- `git diff --check`、IssueテンプレートとDependabot設定のYAML構文確認、`git fsck --full`が成功
- JAR内のMOD ID、バージョン、Minecraft 1.21.10、クライアント専用設定を確認
- JAR内に予期しない実行ファイル、ネイティブライブラリ、外部実行スクリプトがないことを確認
- リポジトリとJARの`LICENSE`、`NOTICE.md`がLF改行であることを確認
- 公開ファイルとJARに、個人情報、ローカルの絶対パス、認証情報、トークン、Webhook、秘密鍵がないことを確認

公開中の`1.0.1` JARとのエントリ単位比較では、バージョン情報と同梱文書の改行正規化だけが変わり、すべての`.class`、画像、言語ファイル、Mixin設定、安全制限リソース、同梱ライブラリは一致します。MODの実行時動作と安全制限に変更はありません。

GitHub Actions上のUbuntuビルドは、`1.0.2`を公開するまで未確認です。

## 確認コマンド

WindowsではJava 21を使用して次を実行します。

```powershell
.\gradlew.bat clean :common:test :fabric:build --console=plain
```

確認項目は次のとおりです。

- JAR名が`freecam_for_ys-fabric-1.0.2+mc1.21.10.jar`であること
- カメラ、Tripod、保存地点、移動APIが実プレイヤーから50ブロック以内に制限されること
- 未読込チャンク、ブロックに重なる移動先、異常な座標が拒否されること
- 攻撃、採掘、設置、使用、ブロック・エンティティ操作、スポイトが動作しないこと
- 被ダメージ、死亡、リスポーン、ディメンション移動、切断時にFreecamが終了すること
- F1で通常HUDを隠してもウォーターマークが表示され、F2スクリーンショットにも残ること
- 通常版FreecamとLegacyFreecamを同時導入できないこと

## 限界

ローカルビルドと自動テストだけでは、利用目的、別MODによる改変、録画後の切り抜き、実サーバー上のすべての状況までは確認できません。管理者が指定した版とサーバールールを優先してください。
